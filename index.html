Paste the Web App URL from your private Apps Script deployment to connect with full read/write access on this device. (Visitors without this URL automatically see a live read-only view instead, if you've set one up — see the read-only script's setup guide.)

"Push" is for one-time setup only — the very first time you connect, to seed an empty Sheet with this device's flights. Once connected, every add/edit/delete already goes straight to the Sheet, so you should rarely (if ever) need Push again. If you're not sure, use "Pull" instead — it's always safe.
Backup & restore
everything you add/edit/delete lives only in this browser — back it up regularly
When connected to a Google Sheet, backups capture and restore everything in that Sheet. When not connected, backups capture and restore this browser's local additions/edits only — the original 409-flight log baked into this file is never affected either way.
